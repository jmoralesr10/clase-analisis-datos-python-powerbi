# 📊 Clase: Análisis de Datos con Python y Power BI

## 📋 Descripción General
Curso completo de análisis de datos donde aprenderás a identificar oportunidades, riesgos, patrones y a crear modelos predictivos con visualizaciones en Power BI.

**Duración:** 5 horas  
**Nivel:** Básico e Intermedio  
**Idioma:** Español

---

## 🎯 Objetivos Generales

1. Identificar oportunidades, riesgos y patrones en datos de ventas
2. Crear segmentaciones básicas de datos
3. Desarrollar un modelo predictivo simple
4. Visualizar resultados en Power BI
5. Generar recomendaciones basadas en datos

---

## 📚 Contenido de la Clase

### **Tema 1: Identificación de Oportunidades, Riesgos y Patrones** (2 horas)

- **1.1 Conceptos fundamentales**
  - ¿Qué son oportunidades, riesgos y patrones?
  - Importancia del análisis de datos

- **1.2 Análisis exploratorio de datos (EDA)**
  - Carga y exploración del dataset
  - Estadísticas descriptivas
  - Identificación de anomalías

- **1.3 Patrones y tendencias**
  - Series temporales básicas
  - Correlaciones entre variables
  - Segmentación inicial

- **1.4 Recomendaciones basadas en datos**
  - Cómo interpretar resultados
  - Generación de insights

---

### **Tema 2: Python - Segmentación y Modelos Predictivos** (2.5 horas)

- **2.1 Segmentación básica (RFM)**
  - Recency, Frequency, Monetary
  - Clustering simple
  - Interpretación de resultados

- **2.2 Modelo predictivo simple**
  - Regresión lineal
  - Predicción de ventas
  - Evaluación del modelo

- **2.3 Visualización de resultados**
  - Gráficos con Matplotlib y Seaborn
  - Exportación de datos para Power BI

---

### **Tema 3: Power BI - Visualización Avanzada** (0.5 horas)

- Conexión de datos
- Creación de dashboards
- Medidas DAX básicas
- Publicación de reportes

## 🚀 Cómo Comenzar

### Requisitos
- Python 3.8+
- Jupyter Notebook
- Librerías: pandas, numpy, matplotlib, seaborn, scikit-learn
- Power BI Desktop

### Instalación
```bash
pip install pandas numpy matplotlib seaborn scikit-learn jupyter
```

### Ejecución
```bash
jupyter notebook
# Abre los notebooks en orden: 01 → 05
```
